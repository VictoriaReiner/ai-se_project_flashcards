# Flash Card App

A responsive web application for creating, organizing, and studying flashcard decks. Built using HTML, CSS (BEM methodology and CSS Grid), and JavaScript.

# Features Added

- Responsive Layouts: Full mobile responsive design across Home, Deck View, and Carousel View down to 320px screen width.
- Dynamic Mobile Navigation: Custom fixed mobile bar with view-aware gradient overlays and location-based button actions (`+ New Deck`, `+ New Card`, `Practice`).
- CSS Grid Carousel: 2-row mobile grid layout positioning flashcards and controls (`<`, `Flip`, `>`) seamlessly.
- Figma Box Shadows: Multi-layered inset and drop box shadows matching design specifications.
- View Routing: JavaScript hash-based routing (`#home`, `#deck/`, `#carousel/`) with dynamic modifier class toggling (`page_no-mobile-bar`).
