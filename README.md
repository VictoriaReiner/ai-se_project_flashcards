# Flash Cards Application

A web application for creating, managing, and practicing flashcard decks to master web development concepts.

## Key Features

- **Remote API & Database Integration:** Connects asynchronously to a remote REST API database to fetch, create, and delete flashcard decks, ensuring data persists across page reloads.
- **New Deck Creation:** Interactive form supporting color selection and JSON validation to dynamically construct and save new flashcard decks.
- **Modal Error Handling:** Custom popup modal that intercepts API network errors and invalid form submissions with user-friendly error notifications.
- **JSDoc Code Documentation:** Complete codebase documentation using JSDoc annotations for improved code readability, parameter tracking, and explicit return types.
- **Single-Page Application Routing:** Hash-based router (`#home`, `#deck/:id`, `#carousel/:id`, `#new-deck`, `#about`) providing instant view navigation without full page reloads.

## Technologies Used

- HTML5 & CSS3 (BEM methodology, Flexbox, CSS Grid)
- JavaScript ES6 (Modules, Fetch API, Promises, Hash Routing)
- REST API Integration
- JSDoc
